# 风格续写小说家 · 部署说明

通用小说风格续写引擎：学习参考小说的写作风格，按章节大纲和字数续写风格一致、剧情连贯的长篇小说。

## 使用方式

1. **导入专家**：将 `专家包_style-novelist` 目录放入 WorkBuddy 专家目录
   - 默认位置：`~/.workbuddy/plugins/marketplaces/my-experts/plugins/`
2. **注册**（如未自动识别）：
   ```bash
   python3 scripts/register_expert.py <expert-dir> --session-id <your-session-id>
   ```
3. **开始使用**：
   - 喂参考文章（可多篇）→ 专家提炼风格画像
   - 提供世界观/人物/大纲 → 专家建立故事圣经
   - 每章给「章节大纲 + 目标字数」→ 专家按风格续写并同步记忆

## 工作流

```
风格学习 → 故事设定 → 章节写作 → 归档更新 →（下一章循环）
```

核心文件：`style-profile.md`（风格画像+锚点）、`story-bible.md`（人物/伏笔/时间线）、`chapters/chapter-NNN.md`（章节正文），全部落盘工作区 `novels/<小说名>/`，跨会话续写不失忆。

## 文件结构

```

```
