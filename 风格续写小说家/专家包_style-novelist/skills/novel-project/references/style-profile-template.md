# 风格画像模板

> 用法：分析用户提供的参考文章后，按此结构产出风格画像，写入 `novels/<小说名>/style-profile.md`。所有条目必须基于参考文章的实际文本证据，不得空泛概括。支持多篇参考交叉提炼（标注「多篇综合」）。

## 一、文体与类型定位

- **题材类型**：（如：都市悬疑 / 古代权谋 / 穿书沙雕流 / 科幻硬核……）
- **叙事人称与视角**：（第一人称/第三人称；单视角/多视角；是否穿插配角视角）
- **时态与叙述基调**：（现在时/过去时；冷峻/幽默/温情/热血……）

## 二、用词习惯

- **词汇偏好**：（高频词、惯用短语、网络梗/方言/古语的使用情况）
- **避用词**：（参考文中几乎不出现的词类）
- **修辞习惯**：（比喻密度、夸张、反讽等）

## 三、句式与节奏

- **句子长度**：（短句为主/长句为主/长短交替；平均句长感觉）
- **段落长度**：（单段平均行数；是否偏好一段一句话）
- **节奏特征**：（对话推进快/描写铺陈慢；紧张场景如何加速、抒情场景如何减速）

## 四、对话风格

- **对话占比**：（约 X%；对话是否是主要推进手段）
- **说话方式**：（口语化程度、省略句、打断、潜台词）
- **语气词与标点**：（波浪号、省略号、问号叹号的使用习惯）
- **内心独白/OS**：（是否存在；占比；功能——吐槽/解说/揭示心理）

## 五、描写偏好

- **写景**：（少/中/多；是否整段写景；景物是否承载情绪）
- **动作**：（动作描写密度；是否用短促动词）
- **心理**：（心理描写的深度与方式——直接叙述/借动作/借对话）
- **三者的比例**：（约 X : Y : Z）

## 六、叙事结构

- **章节开头模式**：（直接进场景对话/环境起笔/倒叙/设问）
- **章节推进模式**：（冲突-解决-新冲突 / 层层铺垫 / 多线并进）
- **章节结尾模式**：（必留钩子/平稳收束/悬念+转折；钩子的常见类型）
- **章节标题风格**：（数字+短句 / 玩梗 / 一句话行动 / 无标题）

## 七、情绪与主题

- **情绪密度**：（每章笑点/泪点/爽点的数量感觉）
- **主题倾向**：（成长/复仇/守护/逆袭……）

## 八、标点与格式

- 标点特殊习惯：（省略号、破折号、引号用法、波浪号）
- 格式习惯：（分段节奏、数字写法、英文/符号混用）
