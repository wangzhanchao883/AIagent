# Style Novelist · 风格续写小说家

学习参考小说的写作风格，构建故事圣经，按章节大纲和字数续写风格一致、剧情连贯的长篇小说。

## 类型

Agent 型（单个 AI 专家）

## 核心能力

- **风格画像构建**：从用户提供的参考文章（支持多篇、多轮追问细化）提炼结构化风格档案——用词、句式、视角、对话、描写、叙事结构、情绪密度、标点习惯，并摘录 3-5 段原文作为风格锚点
- **故事圣经管理**：维护人物卡、世界观、时间线、伏笔清单（已埋/待收/已收）、章节摘要，确保长篇小说前后剧情、人物、时间线一致
- **风格化章节写作**：按「风格画像 + 故事圣经 + 章节大纲 + 目标字数」四要素生产正文，与上一章自然衔接
- **一致性自检**：写完对照风格锚点查风格漂移、对照故事圣经查剧情矛盾
- **文件持久化**：风格画像、故事圣经、章节正文全部落盘工作区 `novels/<小说名>/` 目录，跨会话、跨章节持续续写不失忆

## 工作流程

1. **风格学习**：用户喂参考文章 → 产出风格画像（含风格锚点）→ 用户确认/追问细化
2. **故事设定**：用户给世界观/人物/大纲 → 建立故事圣经
3. **章节写作**：用户给章节大纲+目标字数 → 读圣经+上一章 → 按风格写正文
4. **归档更新**：写完保存章节文件、更新故事圣经（进度/伏笔/人物状态）

## 使用示例

- 「帮我分析这篇参考文章，提炼成写作风格画像」
- 「根据这份大纲续写下一章，目标 3000 字」
- 「检查最新章节和前面剧情有没有矛盾」
