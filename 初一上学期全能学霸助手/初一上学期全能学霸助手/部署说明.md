## 🚀 部署步骤

### 第一步：安装 WorkBuddy
在新电脑上安装 WorkBuddy 桌面应用（如果尚未安装）。

### 第二步：导入专家包

方法一（推荐）—— 复制到插件目录：
1. 将 `专家包_grade-7-tutor/` 整个文件夹复制到新电脑的以下位置：
   ```
   C:\Users\<你的用户名>\.workbuddy\plugins\marketplaces\my-experts\plugins\
   ```
2. 重启 WorkBuddy
3. 在专家市场（Expert Marketplace）中即可看到"学霸王满"，点击启用

方法二 —— 手动注册（如果方法一不可用）：
```
python3 scripts/register_expert.py <专家包路径>
```

### 第三步：放置电子书
建议将 `电子书/` 文件夹拷贝到 D 盘根目录，保持路径为：
```
D:\电子书\
```
（如果放在其他位置，使用时告诉"学霸王满"电子书的新路径即可）

### 第四步：放置笔记文件夹（可选）
建议将 `笔记/` 文件夹拷贝到：
```
D:\笔记\学习\
```
这样 Obsidian 可以无缝读取之前生成的笔记文件。

### 第五步：在 WorkBuddy 中配置（可选）
如果你希望"学霸王满"在新电脑上也记住你的偏好，请参考 `配置说明/用户偏好设置.md` 中的内容。

## 📋 使用说明

### 启动对话
在 WorkBuddy 中选择"学霸王满"专家，开始对话即可。
默认启动语：
> "哈喽！我是学霸王满，你的初一全科学习助手～ 今天想搞定语文、数学还是英语呀？要讲课文、刷知识点，还是制定预习计划？"

### 支持的功能
- 📖 **语文**：课文精讲、文言文翻译、阅读理解答题模板
- ➗ **数学**：概念讲解、公式推导、解题思路引导
- 🔤 **英语**：音标发音、语法讲解、课文逐句翻译
- 📝 **预习计划**：一键生成各科预习方案
- 📚 **教材同步**：基于人教版/北师大版教材内容讲解

### 注意事项
- ❌ 专家不会直接给作业答案，而是引导你思考推导
- ❌ 讲解内容严格贴合教材，不超纲
- ✅ 听不懂随时说，会换更简单的方式再讲一遍

## 🔧 常见问题

**Q: 导入专家包后看不到"学霸王满"？**
A: 尝试重启 WorkBuddy。如果仍然看不见，检查 `专家包_grade-7-tutor/` 文件夹结构是否完整。

**Q: 电子书放在别的盘可以吗？**
A: 可以。使用时告诉"学霸王满"新的电子书路径即可，他会在对应路径查找教材。

**Q: 之前的笔记怎么导入 Obsidian？**
A: 将 `笔记/` 文件夹拷贝到你的 Obsidian 笔记仓库目录下即可。
