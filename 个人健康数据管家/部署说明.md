# 健康数据管家 · 部署说明

适用版本：1.4.0（WorkBuddy 与豆包通用）
安装包下载：<https://github.com/wangzhanchao883/AIagent/releases/latest>

---

## 一、装之前先确认三件事

1. **你的 AI 助手装在电脑上**，不是只用网页版。豆包要用「桌面版 / 工作版」，WorkBuddy 用桌面客户端。
2. **执行环境选「本地电脑」**。豆包的任务模式如果选「云电脑」，那是一个隔离沙箱，看不到你电脑上的数据库，装了也用不了。
3. **电脑装过 Python**（3.10 以上）。没有也没关系，第一次配置时助手会引导你装。

---

## 二、包里有什么

| 文件 | 给谁用 | 说明 |
|---|---|---|
| `health-data-steward-workbuddy.zip` | WorkBuddy | 专家包，多一层外壳 |
| `health-data-steward-doubao.zip` | 豆包 | 技能包，标准 Agent Skills 结构 |

两个包的核心是**同一份** `SKILL.md` 和 12 个脚本，逐字节相同。区别只是 WorkBuddy 多一个 `plugin.json`、人设文件和头像。

选错也不会坏，只是入口对不上。

---

## 三、WorkBuddy 安装

### 方式一：复制到插件目录（推荐）

1. 解压 `health-data-steward-workbuddy.zip`，得到 `health-data-steward-1.4.0/` 目录
2. 把整个目录复制到：

```
C:\Users\<你的用户名>\.workbuddy\plugins\marketplaces\my-experts\plugins\
```

3. 重启 WorkBuddy
4. 在「专家中心」找到「健康数据管家」，启用

### 方式二：从专家市场安装

如果你是从 WorkBuddy 平台的专家市场下载的，直接在客户端里点安装即可，不用管这个仓库。

### 验证装好了

新开一个会话，对助手说「记一下我今早 145.2 斤」。它应该先问你身高年龄这些配置信息，而不是直接记数——说明技能被正确加载了。

---

## 四、豆包安装

1. 解压 `health-data-steward-doubao.zip`，得到 `health-data-steward/` 目录
2. 打开豆包的「工作」模式
3. 找到**技能**入口，选择上传技能
4. 选中解压出的 `health-data-steward/` 整个目录

> 不同版本的豆包上传入口可能要求 zip 或目录。如果它只接受 zip，直接选 `health-data-steward-doubao.zip`（包内顶层就是 `health-data-steward/`，不会散开）。
> 上传成功后，技能会落到豆包工作区的 `.user_skills/` 目录下。

### 验证装好了

在同一个会话里说「先帮我配置一下健康数据管家」，它应该开始问身高、年龄、目标体重、单位。

## 五、首次配置（两个宿主一样）

对助手说一句「先帮我配置一下健康数据管家」，然后照它的提问回答：

1. **身高**（厘米）
2. **年龄**
3. **目标体重**
4. **体重单位**：斤 还是 公斤

这四个数缺一不可——算基础代谢和热量缺口要用。单位一定要说清楚，说「130 斤」和「130 公斤」差一倍。

然后它会自己做：

- 在 `~/health-data` 建目录（Windows 下是 `C:\Users\<用户名>\health-data`）
- 生成配置文件
- 建 SQLite 数据库
- 装唯一依赖 PyYAML
- 跑一遍自检，把结果列给你看

**它会拒绝把项目放在 OneDrive / 百度网盘 / iCloud 这类同步目录。** 这不是刁难，数据放云盘就等于上云了。

## 六、日常怎么用

| 你想做的 | 就这么说 |
|---|---|
| 记体重 | 发一张体重秤照片，或直接说「今早 145.2」 |
| 记一餐 | 发餐食照片 + 一句补充（「家里做的，油不多」） |
| 出报告 | 「出一下昨天的健康日报」 |
| 补漏记 | 「补一下 10 月 25 号的晚餐」 |
| 查趋势 | 「我这周体重怎么样」 |
| 接小米手环 | 「帮我接一下小米手环」（可选，需要你自己扫码登录） |

手机端也可以用，前提是**电脑开着、桌面端助手在线**，手机只是遥控它。电脑关机的话，当天不会跑，也不会自动补。

## 七、数据在哪

```
C:\Users\<你的用户名>\health-data\
├── data\health.db           ← 你的全部记录
├── config\config.yaml       ← 身高年龄目标这些
└── reports\                 ← 生成的 HTML 报告
```

**这个目录永远不要放进任何 git 仓库，也不要放到同步网盘。** 里面有你的体重、三餐、睡眠、心率。

删掉整个 `health-data` 目录就等于彻底清空，没有云端备份——这是设计如此，不是缺陷。

## 八、常见问题

**Q：装了但助手好像没读到技能，直接开始记数了？**
说明技能没加载。WorkBuddy 检查插件目录是否放对、有没有重启；豆包检查技能是否显示在技能列表里。

**Q：配置时报「找不到 Python」？**
让助手帮你装 Python 3.10+，装完重开一个会话再试。

**Q：豆包提示「没有漏记」但我明明记得漏了？**
这是已知限制。漏记巡检依赖 WorkBuddy 的附件台账，豆包上没有这张台账，脚本会报「没有漏记」且退出码为 0（假阴性）。**别信这句承诺**，判断有没有漏要看数据形态：某天有体重没餐食、三餐只录了一餐、某个数据源连续两天为 0。

**Q：项目能不能换个盘放？**
可以，但要设环境变量 `HEALTH_ROOT` 指向新位置。直接给脚本传 `--root` 参数会被静默忽略（已知问题，1.4.0 未修）。

**Q：小米手环连不上？**
小米接入是第三方逆向项目（mi-fitness-mcp-cn，MIT 协议，非小米官方），小米改版就可能失效。失效时它会如实告诉你，不会装作没事。扫码登录必须你本人操作。

## 九、安全边界

这个技能**不做**这些事：

- 不做疾病诊断
- 不给药物、补剂建议
- 不给极端饮食方案
- 不解读异常心率、血氧、血压数值——发现异常只做一件事：标记 + 建议就医

所有建议限定在生活方式层面：作息、饮食结构、运动量、体重趋势、腰围。营养一律给区间和置信度，从不给点值，因为油量是最大误差源。
