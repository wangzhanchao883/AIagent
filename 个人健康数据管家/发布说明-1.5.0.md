# 发布说明 · 1.5.0

**一句话**：把「配餐建议怎么写」从随意发挥变成固定格式——**先给能抄走的结果，再给理由**；同时补了三个报告缺陷。

---

## 一、为什么要改

1.4.0 解决了「装得上」的问题。1.5.0 解决「答得对不对、好不好用」的问题。

真实反馈是这样的：用户问「晚上吃什么」，1.4.0 给出的回答是——先分析今天吃了什么、超了哪几项、为什么这么判断，最后才说吃什么。**内容是对的，但答案在第 800 字之后。**

这类回答把推理过程当成了交付物。1.5.0 把顺序倒过来：**第一屏就是结果**，想深究的人再往下读。

---

## 二、输出规范升级为三条硬规则

写在 `SKILL.md` 第六节，优先级高于文件内其他所有表述。

### 规则 1 · 答案先行，理由在后

固定五段顺序：

**① 一句话结论 → ② 结果表 → ③ 缺口表 → ④ 依据 → ⑤ 偏差与不确定项**

- **结果表必须排在缺口表之前**：先给答案，再用缺口表解释「为什么是这些答案」。反过来就是不合格输出。
- **禁止**开头写「我查了一下」「先看看今天的数据」「让我算一下」——全部挪到第④段。
- 判断标准：只看第一屏就能去执行。
- **不适用于**数据录入回执——那类仍按「已记了什么 → 数字 → 结论」走。

### 规则 2 · 重量一律折算成熟重

对用户呈现的食材重量一律写**熟重**，**结果表里不出现「生重」**。

每日推荐量本身是生重口径（指南如此），所以必须**先折算再写**。内置系数表：

| 类别 | 生 → 熟 |
|---|---|
| 米饭 / 杂粮饭 | × 2.2–2.5 |
| 挂面 / 干面 | × 2.0–2.3 |
| 叶菜 | × 0.7–0.8 |
| 瓜茄、菌藻、豆芽 | × 0.85–0.95 |
| 畜禽肉（炖/煮/炒） | × 0.65–0.75 |
| 豆腐 / 豆制品 | × 1.0 |
| 水果 | 不折算，按可食部称 |

拳数本来就是熟重净重（一拳 ≈ 100–130 g），不用再折。热量和蛋白不受影响——水没有热量，改的只是呈现数字。

### 规则 3 · 按六类营养素枚举缺口，食物种类只作建议

六类固定顺序：**碳水 → 蛋白 → 脂肪 → 钙 → 蔬菜纤维 → 钠**。每类给「已摄入 / 每日目标 / 缺口或超额 / 优先补什么」四列。

关键一条：**总体控营养素，不锁死食物来源。**

- 蛋白缺口用肉类、蛋清、蛋白粉、豆制品都行，**给等价换算让用户选**，只标代价差异（脂肪、热量、饱腹感）
- 某来源已超额时，写「**已超 + 继续用的代价**」，不写成禁令——选择权归用户
- **唯一硬禁令是钠**：钠超了没有替代方案，必须写「别再补」

这条是 1.4.0 的实质缺陷：之前会因为「畜禽肉额度已超」就把蛋白来源锁死到豆腐，而豆制品的氨基酸谱本身要靠多种食物互补，不是唯一解。

## 四、修的三个缺陷（都是用户看得见的错）

### 1. 睡眠柱状图上界重复计，把所有柱子压扁

- **现象**：某些夜晚柱状图顶到 16.8 小时，其他夜晚的柱子被压得看不出差别
- **原因**：上界取 `total_min + awake_min`，而 `awake_min` 本身已含在 `total_min` 里 → 重复计算
- **修复**：上界改用「分期之和」与「卧床时长」的**较大值**；柱高 = 卧床，标注写实睡 = 卧床 − 清醒

### 2. 严重缺觉时仍建议「按计划训练」

- **现象**：用户只睡 4 小时，报告还在催「今日安排一次 40 分钟中强度运动」
- **修复**：昨夜睡眠 < 5 小时时，运动建议整体降级为「只做低强度，散步 20–30 分钟，先补觉」
- **理由**：缺觉时练得越狠恢复越差，减重期更不能靠「多练」补「没睡」

### 3. 休息日被催「补走」「今日补一次」

- **现象**：计划里的休息日步数低（本来就该低），报告却提示「未达标，晚饭后补 20 分钟步行」
- **修复**：判定锚定**星期几**而不是步数——落在 `workout_plan.rest_weekdays` 里的日子，步数低属正常，明确写「不必补走」；休息日 0 分钟中高强度也属计划内，不催「今日补一次」

### 4. 同日夜间睡眠与午睡互相覆盖（`sync_band.py`）

- **现象**：某天同时有夜间主睡眠和午睡时，入库数据自相矛盾（`total=45` 而 `light=387`）
- **原因**：源库 `is_nap` 字段实测全为 0，判不出午睡；旧逻辑用 COALESCE 混搭两行
- **修复**：同一归属日多会话时**只入库时长最长的一条**作为主睡眠；已有记录时**整行替换**，不再混搭
