## 🚀 部署步骤

### 第一步：安装 WorkBuddy
在新电脑上安装 WorkBuddy 桌面应用（如果尚未安装）。

### 第二步：导入专家包

方法一（推荐）—— 复制到插件目录：
1. 将 `专家包_woop-wish-coach/` 整个文件夹复制到新电脑的以下位置：
   ```
   C:\Users\<你的用户名>\.workbuddy\plugins\marketplaces\my-experts\plugins\
   ```
2. 重启 WorkBuddy
3. 在「专家中心」即可看到"woop愿望行动咨询师"，点击启用

方法二 —— 手动注册（如果方法一不可用）：
```
python3 scripts/register_expert.py <专家包路径>
```

## 📋 使用说明

### 启动对话
在 WorkBuddy 中选择"woop愿望行动咨询师"专家，直接说出你的愿望即可。
默认启动语：
> "我有一个愿望想实现，帮我看看到底行不行"

### 工作方式
1. 你说出一个愿望 → 专家评估可行性（只判时间/物理/现实铁律，不做主观否决）
2. 明显不现实 → 帮你重设为同向的合理愿望（保留动机内核，降难度、加时限）
3. 可行或存疑 → 引导你完成 WOOP 四步：愿望 → 结果 → 障碍 → 计划
4. 全程尽量不提问，信息不足时最多补充 3 轮问答

### 科学依据
- **心理比对**（Mental Contrasting）：先想愿望实现的美好，再想内心障碍，二者对峙 → 愿望可行则加速行动，不可行则及早抽身（第4章）
- **执行意图**（Implementation Intentions）："如果障碍出现，那么我就做 Y" → 让行动在障碍出现时自动触发（第6章）
- 实证覆盖健康、康复、戒瘾、恋爱、学业、职场六大领域（第7章）
