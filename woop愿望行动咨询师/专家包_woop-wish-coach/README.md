# woop愿望行动咨询师

基于《WOOP思维心理学》（加布里埃尔·厄廷根 著）打造的行为咨询专家。你说出一个愿望，它先评估这个愿望到底能不能实现——明显不现实的愿望帮你重设为一个同向的合理愿望；可行或存疑的愿望直接进入 WOOP 四步规划（愿望→结果→障碍→计划），产出可执行的"如果……那么……"行动方案。全程尽量不提问，信息不足时最多补充 3 轮问答。

## 类型

Agent 型（单个 AI 专家）

## 核心方法：WOOP 四步法

| 步骤 | 含义 |
|------|------|
| W Wish | 愿望：有点难但能达成的目标（含时限） |
| O Outcome | 结果：生动想象实现后的最佳画面 |
| O Obstacle | 障碍：用户自述的内心最深障碍（AI 引导深挖，不代答） |
| P Plan | 计划："如果障碍出现（何时何地），那么我就做具体动作 Y" |

依据：心理比对（先想结果再想障碍，次序不可颠倒）+ 执行意图（如果……那么……）合体即 WOOP，行为改变领域证据最扎实的低成本工具之一。

## 功能

- **愿望可行性评估**：区分硬性不可行（违反时间/物理/现实铁律）与存疑愿望
- **同向降级**：不可行的愿望重设为保留动机内核、降难度加时限的合理愿望
- **WOOP 四步引导**：严格按序，障碍由用户自己说出，AI 只引导深挖
- **中途抽身**：用户在障碍环节自判愿望不现实时，允许调整愿望重做，不硬推
- **最小化问答**：能推断就不问，全程 ≤3 轮

## 使用示例

- "我有一个愿望想实现，帮我看看到底行不行"
- "帮我做一次WOOP规划，让愿望真正落地"
- "我这个目标好像不现实，帮我调整成一个能做到的"

## 安装

将专家包目录放到专家目录下：

```
C:\Users\<你的用户名>\.workbuddy\plugins\marketplaces\my-experts\plugins\woop-wish-coach\
```

重启 WorkBuddy，在「专家中心」即可看到"woop愿望行动咨询师"。若未自动出现，运行注册命令：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r woop-wish-coach.zip woop-wish-coach/
```
