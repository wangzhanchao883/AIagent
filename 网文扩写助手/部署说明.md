## 🚀 部署步骤

### 第一步：安装 WorkBuddy
在新电脑上安装 WorkBuddy 桌面应用（如果尚未安装）。

### 第二步：导入专家包

方法一（推荐）—— 复制到插件目录：
1. 将 `专家包_wangwen-writer/` 整个文件夹复制到新电脑的以下位置：
   ```
   C:\Users\<你的用户名>\.workbuddy\plugins\marketplaces\my-experts\plugins\
   ```
2. 重启 WorkBuddy
3. 在「专家中心」即可看到"网文扩写助手"，点击启用

方法二 —— 命令行注册：
```bash
cd <expert-manager脚本目录>
python scripts/register_expert.py <专家包目录>
```

### 第三步：使用
- 直接在对话中提供**章节剧情大纲**，专家按参考风格扩写成 2000~3000 字正文
- 支持追问：`先给我看看风格指南和角色设定`、`把这段草稿改写成符合参考风格`

---

## 📌 使用说明

- **输入**：每章剧情大纲（人物、事件、冲突、转折、悬念）
- **输出**：完整章节正文（对话驱动、现代梗穿越、章末钩子）
- **风格基底**：三份参考稿综合提取，覆盖第 1-8 章 + 夜袭草船借箭，扩写自动延续核心伏笔（密令、白衣女子、无金手指等）
