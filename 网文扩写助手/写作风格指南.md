# 网文写作风格指南
（依据参考稿三份综合提取：参考1=前5章、参考2=第6-8章、参考3=夜袭蒙营·草船借箭，2026-08-01 更新）

## 一、题材与类型定位

- **类型**：穿书/穿越 + 古代架空（大夏王朝）+ 战争 + 喜剧沙雕流
- **核心爽点**：现代社畜主角用「嘴炮 + 现代思维 + 现代军事知识」降维打击古代人
- **叙事基调**：轻松搞笑为主，战斗为辅，冲突靠「说」不靠「打」
- **总字数参考**：单章约 2000~3000 字，参考2、3 显示后期篇幅可略增
- **风格演进**：三份参考呈现明显成长轨迹——前期（参考1）糙、口语化、对话密度极高；中期（参考2）描写和心理刻画明显增强；后期（参考3）节奏最快、现代梗最密、开始用敌方视角穿插。**扩写应以中后期成熟风格为准**：对话仍为主引擎，但允许适度描写润色、心理戏加强、可穿插反派视角。

## 二、结构特征

1. **章节标题**：数字 + 短句玩梗，口语化、反问句/惊叹句
   - 例：《1、我穿书了 但是女频》《2、打什么仗？》《3、5千VS 5万？》《4、喷垃圾话我在行》《5、这都能赢？》《7、下马威还是要有的》《8、头疼，让我捋捋》《9、柱子这是飘了》
   - 部分后期章节也可用一句话标题（如《夜袭蒙营，草船借箭》）
2. **开头方式**：直接进入场景对话，零铺垫（例：开头就是主角躺床上接老妈电话）
3. **场景切换**：短平快，一段环境描写 + 动作 + 对话推进
4. **章末钩子**：每章结尾必留悬念（例：白衣女子出现、柱子欲言又止、夜袭出发）
5. **节奏**：段落极短，一句话一段是常态；对话占全文 60% 以上（参考3 现代梗密度最高，可用「稳得一批」「心态崩了」「血赚」等网络用语强化喜感）

## 三、语言风格

1. **口语化、市井化**：卧槽、告辞、牛逼、铁憨憨、搞什么、得嘞、心态崩了、稳得一批、秒认怂、拉满
2. **语气词波浪号**：妈~、将军~、小的~、行~行~、这~这~
3. **拟声词**：嘟~嘟~嘟（挂电话）、嗖~嗖/飕飕（箭矢）、噗~噗（中箭/捅人）、咄~咄~咄（箭扎盾）、哇哇（呕吐）
4. **现代梗穿越古代**：
   - 职场梗：牛马、销售冠军、请同事喝茶K歌被背刺、老板谁说话好听听谁的
   - 网络梗：卧槽、牛逼、破鞋、男宠、剧组、人设、穿越、系统绑定、金手指、寄了、血赚
   - 知识梗：草船借箭、三十六计、孙子兵法、编制（连/排/营）、稻草盾
   - 生活梗：显卡球鞋、洗脚城、电影桥段（狐妖女鬼）、蚊子多
5. **内心 OS 吐槽体**：主角大量内心独白，直接吐现代人槽
   - 例："打仗我是不会，喷人我还没输过呢"
   - 中期起：穿插长篇心理戏（例：杀人后的爽快感自省、对穿越无金手指的抱怨）
6. **夸张比喻**："羽箭如流星""黑压压的蒙军""怒吼如实质""杀气有实质般""眼神稳得一批"
7. **错位幽默**：古代严肃场景 × 现代轻佻思维（例：监军骂完，主角只记得"他夸我帅"）
8. **敌方视角穿插**（参考3 特色）：用敌方将领的心理反应来烘托主角计谋的高明（例：张奔视角——自负→谨慎→中计）

## 四、扩写时必须遵守的规则

1. **对话是引擎**：剧情靠对话推进，动作和环境做点缀；可写适度描写（参考2、3 级），但不要整段纯写景
2. **保持主角人设**：嘴炮、自恋、善良但不圣母、遇事先吐槽、关键时刻狠得下心（参考2 杀孟斌立威）
3. **冲突解决靠"说"**：能用话术解决的绝不真打，打架也要先喷几句；真动手时干净利落
4. **短段落**：超过 3 行没对话的段落要拆
5. **现代梗适度**：每 2~3 段至少一个笑点；参考3 证明梗可以更密，但保持自然不油腻
6. **每章结尾留钩子**：悬念、误会、新人物、未解之谜任选
7. **人物反应夸张化**：配角听到主角的话要"一脸懵/目瞪口呆/炸了/秒认怂"
8. **保留波浪号语气词** 和 拟声词 的使用习惯
9. **主角内心戏**：遇到新情况先内心吐槽，再行动；大事件后可给一段完整心理复盘
10. **章节标题玩梗**：数字 + 反问/惊叹短句，或一句话行动标题
11. **反派视角可穿插**：敌方视角长度控制在 1/3 章以内，用于烘托主角算计
12. **古代逻辑自洽**：书中世界"重文轻武、讲规矩"的设定要贯穿——骂阵丢脸、偷袭无德、名节大于胜负

## 五、情节套路（本书特色）

1. **知识碾压**：用现代话术/思维破解古代难题（嘴上不积德→激将敌将；草船借箭→空手套箭）
2. **道德绑架反用**：蒙军讲"礼数"，主角就用"礼数"束缚对方；大夏将领讲"名节"，主角就用"要命还是要脸"策反士兵
3. **以小博大**：5千 vs 5万，靠智商和嘴皮子翻盘
4. **误打误撞式胜利**：主角本意是阴招，结果意外大捷，他自己都懵
5. **身份错位**：现代社畜被迫当将军，武力废柴、嘴炮满分；无原主记忆、无系统金手指的"地狱开局"
6. **管理话术**：前世销售经验用于带兵（选排长话术、问"要命还是要脸"、打一棒给一甜枣）
7. **计谋落点都是"借"**：参考3 草船借箭借的是箭和粮——主角的计谋核心是"不损己、占便宜"
